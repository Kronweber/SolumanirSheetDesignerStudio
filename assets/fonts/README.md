# Fonts

Cinzel (headings), Alegreya (body text), Alegreya Sans (labels and the app UI) and Cascadia Mono (code), all under the SIL Open Font License. The licence texts are the `OFL-*.txt` files.

Alegreya Sans is the static release from Google Fonts. Cinzel and Alegreya only come as variable fonts there, so these files are static instances (weights 400, 500 and 700) cut from them with fontTools. Cascadia Mono is the static Regular, Bold and Italic from release 2407.24 of microsoft/cascadia-code.

The file names have to stay as `Family-Style.ttf`. If the files are missing, the app falls back to system fonts.
