# Fonts

Cinzel (headings), Alegreya (body text) and Alegreya Sans (labels and the app UI), all under the SIL Open Font License. The licence texts are the `OFL-*.txt` files.

Alegreya Sans is the static release from Google Fonts. Cinzel and Alegreya only come as variable fonts there, so these files are static instances (weights 400, 500 and 700) cut from them with fontTools.

The file names have to stay as `Family-Style.ttf`. If the files are missing, the app falls back to system fonts.
